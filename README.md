# Space Adventure
2022 Team Project 1 第四組 
***
遊戲說明：
1. 攻擊：怪物撞到玩家會扣血70
2. 血量：一開始1000點血，血條歸零，遊戲結束。
3. 移動控制：角色本身以上(W)下(S)左(A)右(D)進行操作。
4. 武器：以滑鼠決定方向，點擊滑鼠左鍵對怪物攻擊，按Ｑ變更武器，有槍跟刀兩種型態。
